## The "404" mark
- Inline the paths of `mark.svg` in `404.astro`. Keep the `viewBox="0 0 507 255"` and the path data exactly; the box includes the 15 px stroke overflow, so **the SVG box edges are the ink edges**.
- Colour: the two "4" strokes and the "0" stroke use `currentColor` with `color: var(--color-text-brand)` (#1f3bd6). The "0" fill (it covers the "4"s where they cross) is `var(--color-bg-surface)`, not a literal `white`.

**The button is the About section's `.resume-link` (Figma calls the component "Button / View Resume").** Move that rule to one shared class in `global.css` (for example `.button-brand`) and use it in both `AboutSection.astro` and `404.astro`. Hover: `--color-bg-brand-hover`, the existing `--motion-duration-fast` transition, inside `@media (hover: hover)` if About's rule is (keep whatever About does today). Focus: the global `a:focus-visible` ring.

## Vertical layout
- The 404 page's layout is: header, `<main>` that grows to fill the rest of the viewport, footer. `<main>` has `padding-block` = the two minimums above, and centres the content group (mark + heading + button) vertically inside it.
- **The site's header and footer are not Figma's heights** (measured on staging 2026-11-06: header 94 at 1920 / 66 at 390; footer 280.4 at 1920 / 418.6 at 390; Figma: 92 / 295). They stay as they are; the minimums come from Figma.
- **1920 × 1080:** `<main>` = 1080 − 94 − 280.4 = 705.6; content 436 + minimums 257 = 693, so the 12.6 px extra splits equally: header → mark **116.3**, button → footer **153.3**. The mark top sits at 210.3 from the viewport top (Figma 202). The footer bottom edge = viewport bottom, no vertical scroll.
- **390 × 844:** `<main>` = 844 − 66 − 418.6 = 359.4; content 266.75 + minimums 88 = 354.75, so header → mark **42.3**, button → footer **50.3**, no vertical scroll. (The 390 minimums are 40 / 48 so that the tall mobile footer still fits at 844.)
- Taller viewports: the extra height is split equally above and below the content group; the footer stays at the bottom.
- Shorter viewports: the minimums hold and the page scrolls.
- Use `svh` for the viewport height (iOS toolbars).
- **Page-scoped only.** The global `main { min-height: calc(100vh - var(--header-height)) }` and every other page stay unchanged. Remove the `.placeholder-page` rules from `global.css` (only the 404 uses them).
